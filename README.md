# 성장의 기록 — 포트폴리오

하단 중앙 타임라인으로 대학생, 부트캠프, 경력사항 화면을 이동합니다.
휴대폰 화면에서도 메뉴가 하단에 유지되며, 내용은 위아래로 스크롤할 수 있습니다.
흰색 배경과 흑백 톤을 사용하며, 메뉴를 선택하면 해당 방향으로 화면이 좌우로 전환됩니다.
기기의 '동작 줄이기' 설정을 사용하면 애니메이션 없이 바로 전환됩니다.

## 내용 채우기

`dist/content.js`에 각 화면의 내용이 모여 있습니다.

- `fields`: 학교, 기간, 기술, 직무 등의 기본 정보. `value`를 채워 주세요.
- `entries`: 프로젝트 및 활동 목록. 파일 상단의 작성 예시를 참고하세요.
- `tagline`, `description`: 각 화면의 소개 문구.
- `title`: 메뉴에 대응하는 화면 제목.

빈 기본 정보는 '등록 예정', 빈 프로젝트 목록은 안내 문구로 표시됩니다.
실제 학력, 이력, 성과는 입력하지 않은 상태입니다.

## 구성

- `dist/index.html`: 화면 구조
- `dist/styles.css`: 디자인과 반응형 레이아웃
- `dist/content.js`: 수정할 콘텐츠
- `dist/app.js`: 화면 전환 및 콘텐츠 표시

`dist/index.html`을 브라우저에서 열어 로컬로 확인할 수 있습니다.
설치나 빌드 과정 없이 동작하는 정적 사이트입니다.
온라인 게시가 완료된 상태는 아닙니다. 다른 환경에서는 먼저 로컬 파일로 확인하세요.

## 다른 환경에서 이어서 작업하기

`HANDOFF.md`에 현재 요구사항과 구현 상태를 정리했습니다.
다른 PC의 편집기나 코딩 도구에서 이 폴더를 열고 해당 메모를 읽도록 요청하면 됩니다.

GitHub 저장소: https://github.com/gusdn6288/FE_QA
다른 PC에서는 `git clone https://github.com/gusdn6288/FE_QA.git` 명령으로 소스를 받으세요.
다른 PC에서는 저장소를 복제한 뒤 같은 파일을 수정하면 됩니다.
ZIP에는 기존 환경의 `.git/` 및 `.openai/` 설정을 포함하지 않았습니다.
소스 저장소에 올리는 작업과 인터넷에 웹사이트를 게시하는 작업은 별개입니다.

## 화면 주소

- `#university`: 대학생
- `#bootcamp`: 부트캠프
- `#career`: 경력사항

각 화면에서 새로고침과 브라우저의 뒤로/앞으로 이동을 사용할 수 있습니다.
하단 메뉴에 키보드 초점을 둔 상태에서는 좌우 방향키와 Home/End 키도 지원합니다.

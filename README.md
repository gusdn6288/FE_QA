# 김현우 — 성장의 기록

하단 중앙 타임라인으로 대학생, 부트캠프, 경력사항 화면을 이동합니다.
휴대폰 화면에서도 메뉴가 하단에 유지됩니다. 헤더와 푸터 사이의 본문 영역만 위아래로 스크롤되며, 본문이 고정 표시와 겹치지 않습니다.
하늘에 맞춰 글자·시계·메뉴·카드·연혁 선의 색이 변합니다. 밝은 낮에는 짙은 푸른색, 노을에는 따뜻한 색, 밤에는 밝은 푸른색 계열을 사용합니다. 다음 챕터를 선택하면 새 본문이 오른쪽에서 들어오고 기존 본문은 왼쪽으로 나갑니다. 이전 챕터로 돌아갈 때는 반대 방향으로 움직이며, 본문 전환에는 약 0.62초가 걸립니다.
배경은 방문자 기기의 현재 시각을 기준으로 새벽·아침·낮·노을·밤으로 이어집니다. 오전에는 해가 왼쪽에서 떠오르고, 한낮에는 높이 올라가며, 저녁에는 오른쪽으로 저물고 별과 초승달이 나타납니다. 같은 시각에는 모든 챕터에서 같은 하늘을 보여 줍니다. 매초 실제 시각을 읽으므로 페이지를 열어 둔 동안에도 천천히 변합니다. 위치 정보 없이 시간대별 분위기를 표현하며 실제 지역의 일출·일몰을 계산하지는 않습니다.
해는 밝은 중심에서 따뜻하고 투명한 가장자리로 이어지며, 넓은 빛 번짐과 은은한 가로 햇살을 더했습니다. 하늘을 덮던 어두운 레이어는 완전히 제거했습니다. 구름과 햇빛 효과는 유지합니다.
배경은 스크롤 중에도 화면에 고정됩니다. 구름은 천천히 흐르고 별빛은 은은하게 변합니다. 이미지 다운로드 없이 CSS로 표현하고, 숨긴 탭에서는 움직임과 타이머를 멈춥니다. 탭으로 돌아오면 현재 시각에 맞춰 바로 동기화합니다.
기기의 '동작 줄이기' 설정을 사용하면 애니메이션 없이 바로 전환됩니다.

헤더와 하단 메뉴는 스크롤 중에도 고정되며, 검은 배경 띠와 흐림 효과 없이 하늘 위에 표시합니다. 상단에는 로고와 화면 번호, 푸터 중앙에는 챕터 메뉴, 오른쪽에는 연혁 날짜 시계를 배치했습니다. 좁은 화면에서는 메뉴 아래 행의 오른쪽에 시계를 놓습니다. 본문은 가운데 스크롤 영역의 경계에서 잘리므로 투명한 헤더·푸터 뒤에 글자가 보이거나 메뉴 클릭을 가로막지 않습니다. 날짜 시계는 `2019:0301` 형식으로 표시하며, 연혁 사이를 스크롤할 때 중간 날짜를 거쳐 흐릅니다. 숫자가 세로로 이어서 굴러가고 목표 날짜에 가까워질수록 부드럽게 멈춥니다. 스크롤 속도나 방향이 바뀌어도 현재 움직임을 이어가며, 위로 스크롤하면 날짜도 되돌아갑니다.
시계의 검은 틀과 숫자 배경도 제거했고 가운데 `:`는 1초 주기로 깜박입니다. 각 표시와 글자는 화면 내 높이에 해당하는 하늘색을 기준으로 밝거나 어두운 색을 선택합니다. 월만 확인된 이력의 기준점에서는 `2023:0900`처럼 표시하며 `00`은 확인되지 않은 일자를 뜻합니다. 중간 날짜는 시간의 흐름을 표현하기 위한 것으로, 각 이력에 적힌 실제 날짜와 기간은 바뀌지 않습니다.
경력사항의 마지막 지점에서는 오늘 날짜에 도달한 뒤 아래에 `시:분:초`와 `NOW`가 나타납니다. 방문자 기기의 현재 시각으로 매초 갱신하며, 자정이 지나면 날짜도 바뀝니다. 과거로 스크롤하거나 다른 챕터로 이동하면 실시간 표시가 사라집니다. '동작 줄이기' 설정에서는 날짜가 즉시 갱신되고, 깜박임과 전환 효과는 멈추지만 현재 시각의 초는 계속 갱신됩니다.

첫 화면에는 ‘안녕하세요, 소프트웨어 엔지니어’와 ‘김현우입니다.’가 두 줄로 타이핑됩니다.
페이지를 불러온 뒤 첫 대학생 화면에서 한 번 재생되며, ‘저의 여정 보기’를 누르면 챕터 소개로 이동합니다.
글자의 자리를 미리 확보해 타이핑 중 줄이 움직이지 않으며, '동작 줄이기' 설정에서는 완성된 문구를 바로 보여줍니다.

상단은 챕터 소개와 오버뷰를 나란히 배치하고, 하단은 전체 폭의 세로 연혁으로 분리했습니다.
연혁의 날짜와 경험은 시간순으로 연결되며, 모바일에서는 날짜가 각 경험 위에 표시됩니다.
스크롤 위치에 따라 연혁 선이 하늘과 어울리는 강조색의 그라데이션으로 채워집니다. 지나온 날짜 지점과 현재 지점이 강조되고, 위로 스크롤하면 진행 표시도 되돌아갑니다. '동작 줄이기' 설정에서는 선을 완전히 채운 정적인 형태로 표시합니다.

## 콘텐츠 수정

`dist/content.js`에 각 화면의 내용이 모여 있습니다.

- `fields`: 학교, 기간, 기술, 직무 등의 기본 정보. `value`를 채워 주세요.
- `highlights`: 각 화면의 핵심 이력 요약.
- `entries`: 프로젝트 및 활동 목록. `bullets`는 담당 업무, `tags`는 기술·역량, `outcome`은 결과, `details`는 펼쳐보기, `links`는 외부 링크입니다.
- `entries[].date`: 연혁의 연도(`year`), 세부 기간(`label`), 확인된 시작 날짜(`iso`, 선택 사항). 날짜가 없는 경험에는 임의의 날짜를 부여하지 않습니다.
- `historyRange`: 연혁 제목 옆의 전체 기간.
- `credentials`: 자격, 교육 이력 또는 협업 방식.
- `tagline`, `description`: 각 화면의 소개 문구.
- `title`: 메뉴에 대응하는 화면 제목.

빈 기본 정보는 '등록 예정', 빈 프로젝트 목록은 안내 문구로 표시됩니다.
제공된 자기소개서와 증빙자료를 바탕으로 실제 학력, 프로젝트, 보안성 시험 및 문서 자동화 경험을 반영했습니다.
날짜와 담당 범위의 근거는 `CONTENT_NOTES.md`에 정리했습니다. 증명서 원본과 개인 식별정보는 사이트에 포함하지 않습니다.

## 구성

- `dist/index.html`: 화면 구조
- `dist/styles.css`: 디자인과 반응형 레이아웃
- `dist/content.js`: 수정할 콘텐츠
- `dist/app.js`: 화면 전환 및 콘텐츠 표시

`dist/index.html`을 브라우저에서 열어 로컬로 확인할 수 있습니다.
설치나 빌드 과정 없이 동작하는 정적 사이트입니다.
온라인 게시가 완료된 상태는 아닙니다. 다른 환경에서는 먼저 로컬 파일로 확인하세요.

## 다른 환경에서 이어서 작업하기

`HANDOFF.md`에 현재 요구사항과 구현 상태를 정리했습니다.
다른 PC의 편집기나 코딩 도구에서 이 폴더를 열고 해당 메모를 읽도록 요청하면 됩니다.

GitHub 저장소: https://github.com/gusdn6288/FE_QA
다른 PC에서는 `git clone https://github.com/gusdn6288/FE_QA.git` 명령으로 소스를 받으세요.
다른 PC에서는 저장소를 복제한 뒤 같은 파일을 수정하면 됩니다.
수정 내용을 다른 PC에서도 받으려면 GitHub에 커밋과 push가 필요합니다. 다른 PC에서는 `git pull`로 올라온 변경을 받으세요.
소스 저장소에 올리는 작업과 인터넷에 웹사이트를 게시하는 작업은 별개입니다.
